Task 1 — EscapeCodeGenerator ✓

КоммитСодержание
f93d9c4EscapeCodeGenerator.cs + TerminalEscapeAttribute + аннотированные enum StyleFlag, Color8Bit, CursorDirection. Генератор сканирует enum с [TerminalEscape] и эмитит статические классы *EscapeCodes с предвычисленными ECMA-48 последовательностями.

Применение: StyleFlagEscapeCodes.Reset, Color8BitEscapeCodes.Foreground(), CursorDirectionEscapeCodes.Cursor() заменяют ручные \x1b[...m литералы в AnsiEscapeStrategy и потребителях.

Ограничение: Генератор покрывает только SGR (StyleFlag), 256-color (Color8Bit) и CSI cursor (CursorDirection). Truecolor (38;2;R;G;B) и DEC private-mode (?25l, ?1049h) остаются в AnsiEscapeStrategy — они не являются enum-based и не подходят для генерации из атрибута.

Сознательные отклонения от скетча

  • Zero-alloc constraint. Генератор эмитит string свойства/методы, а не ReadOnlySpan<byte>. Это осознанный выбор: string interнируется в пуле строк, а возврат ReadOnlySpan<byte> потребовал бы изменений в потребителях (TextWriter.Write принимает string). Для truecolor-и последовательностей (38;2;R;G;B) interning невозможен из-за переменных компонент — они остаются в AnsiEscapeStrategy с line-by-line выделением.
  • RendererAdapterGenerator: нет Frame() wrapper. Скетч предполагал генерацию IRoundRobinRenderer.Frame(), но фактический Frame() метод живёт в базовом классе AnsiPlainTuiRenderer и не является точкой расширения. Генератор вместо этого предоставляет backend-metadata (CursorFrameBoundary, WriteFramePrologue/Epilogue), которые consumed frame loop'ом.
  • Стиль атрибута [TerminalEscape]. В скетче атрибут упоминается как [TerminalEscape] на enum — это сохранено. Однако ClassName, Namespace, ResetMember параметры атрибута в текущей версии работают только для StyleFlag-кейса; для Color8Bit/CursorDirection они игнорируются (класс именуется как {EnumName}EscapeCodes).
