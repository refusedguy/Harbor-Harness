Hard rules — соблюдение

  • ✅ Малые атомарные коммиты (1–2 файла, harness-коммиты — 3–4 файла новой изолированной инфраструктуры).
  • ✅ Все новые тесты GREEN с первого запуска (load-тесты — после устранения двух багов самого harness'а: незаполнявшийся реестр агентов и не-добавлявшийся user message; фиксы — в harness, не в ослаблении assertions). Никаких ExpectedFail/Skip в новом коде.
  • ✅ Golden-тесты — hash-based: сравнение SHA-256 PNG-байт, «файл существует» не является assertion.
  • ✅ Load harness детерминирован: ни Thread.Sleep, ни Task.Delay на реальное время — только token-bucket refund-on-completion и MockLlmServer.SetChunkDelay (time dilation).
  • ✅ После каждого коммита: пер-проектный dotnet test tests/<Project> -c Release --no-build (+ pre-commit hook harbor-check гоняет arch-gate).
