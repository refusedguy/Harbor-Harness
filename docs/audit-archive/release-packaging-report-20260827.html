2. Ключевая проблема: AOT + плагины

КомпонентТехнологияПочему нельзя объединить
Harbor.App.CliNativeAOTНе может ссылаться на Roslyn / JIT код
Harbor.Plugins.HostJIT + RoslynКомпилирует .cs плагины на лету
IPCstdio / pipe / UDSОбщение между процессами

NativeAOT всегда выдаёт один нативный EXE на одну RID. Он не умеет вложить внутрь себя отдельный JIT-процесс. Поэтому при включённых плагинах — всегда два файла.
