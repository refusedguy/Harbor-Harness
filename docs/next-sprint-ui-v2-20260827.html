Harbor Next Sprint — Competitive UI/UX Analysis

Анализ 6 источников: Kilo Code, OpenCode, Codex CLI, Claude Code, TUI frameworks, Web AI UIs
Executive Summary

Конкуренты уже ушли далеко в сторону анимаций, дизайн-систем и killer features. Harbor сейчас отстаёт по:

  • Panel animations — у конкурентов fade/slide/pulse стандарт, у Harbor нет
  • Command palette — у Kilo/OpenCode/Codex есть, у Harbor нет
  • Sidebar с контекстом — у OpenCode/Cursor есть, у Harbor нет
  • Theme system — у Claude 6 тем + live-reload, у Harbor 1
  • Web UI — у ChatGPT/Claude/Cursor продакшен, у Harbor только заготовки
  • TUI animations — Ratatui/Textual имеют CSS-like transitions, у Harbor нет
Competitive Findings

Kilo Code CLI

  • Warm stone palette (#0c0a09 base, #f9f76f accent)
  • Flex-row main + sidebar (42px)
  • Two-tier tool cards: InlineTool + BlockTool
  • PermissionPrompt с 3-stage flow + live diff preview
  • Command Palette (ctrl+p) с fuzzy search + suggested commands
  • Leader-key system (ctrl+x), Emacs + optional vim editing
  • Thinking blocks render at 72% opacity
  • Petdex mascots as ambient animations
  • Quick-switch slots (<leader>1-9)
  • Cost/token display in prompt footer

OpenCode CLI

  • OpenTUI + SolidJS rendering engine
  • Split layout: main scrollbox + optional 42-char sidebar
  • Rich promptarea: @agent mentions, file attachments, external editor
  • Dialog system: Command Palette, Model picker, Agent picker, Timeline, Fork, Export
  • Plugin-extensible slots: home_logo, home_prompt, home_bottom, home_footer
  • Ghostty-web + Desktop app (Tauri + Electron)
  • CSS-like styling with theme tokens

Codex CLI (OpenAI)

  • Ratatui-based three-zone vertical layout
  • Steer mode: Enter injects mid-turn
  • Plan/Pair/Execute collaboration modes
  • Syntax-highlighted V4A diffs
  • /ide IPC bridge to VS Code/Cursor
  • Configurable keymaps/themes/statuslines
  • Platform-native sandboxing (Seatbelt/Landlock/RestrictedToken)
  • Raw scrollback mode

Claude Code (Anthropic)

  • Forked Ink with React 19 ConcurrentRoot
  • Yoga flexbox layout + double-buffered Int32Array screen buffers
  • 80+ semantic color tokens in typed Theme contract
  • 6 built-in themes: auto, dark, light, dark-daltonized, light-ansi
  • Custom JSON themes with live-reloading in ~/.claude/themes/
  • Dingbat spinner glyphs (✶, ✻, ✳, ✢) with elapsed time and token rate
  • Full vim mode (hjkl, visual selection, yank/paste, indent/dedent)
  • Worktree isolation for parallel sessions
  • Skills & plugins system with hooks
  • Inline diff review (/diff) reconstructed from conversation
  • Extended thinking toggle (Meta+T)
  • OSC 11 auto-theme detection

TUI Framework Patterns

  • Ratatui: tachyonfx shader-like post-render effects, constraint-based flex, layout cache
  • Bubble Tea: harmonica spring physics, Elm-architecture input, Viewport widget
  • Textual: CSS animations, dirty-rect + virtual DOM (120 FPS), DataTable/TreeView/CommandPalette
  • Terminal.Gui: explicit screen-reader support, keyboard-only navigation, Wizard/FileDialog

Web AI UIs

  • ChatGPT: pure-black theme, 260px floating sidebar, pill-shaped composer, 300+ CSS vars
  • Claude: warm-neutral dark, dual typography (sans UI + serif responses), spring-physics buttons, dyslexic font support
  • Cursor: Parallel Agents Window, reviewable multi-file diffs in Composer, Design Mode visual annotation
  • Windsurf/Devin: Cascade flow model, fleet command center for multiple agents, Spaces for shared context

Proposed Next Sprint: UI-V2

Based on competitive analysis, the next sprint should focus on making Harbor visually competitive rather than just functional.

Priority 1: Animations & Transitions (must have)

  • Panel fade-in/slide-in: 150ms fast, 300ms normal, ease-out
  • Tool cards slide-in + fade
  • Approval gate pulse/warn glow
  • Status bar smooth transitions between states
  • Timeline smooth scroll + opacity transitions
  • Spring physics for panel resizing (Bubble Tea harmonica)

Priority 2: Command Palette & Navigation

  • Command Palette (ctrl+p) with fuzzy search + suggested commands
  • Quick-switch slots for recent sessions
  • Leader-key system for power users
  • Vim mode toggle for composer

Priority 3: Theme System Expansion

  • Multiple built-in themes: Harbor Dark, Light, Warm, Cool
  • Custom JSON theme support with live-reload
  • OSC 11 auto-theme detection
  • Per-component theme overrides

Priority 4: Sidebar & Context Panels

  • Optional right sidebar (42px default, auto-show on wide terminals)
  • Plugin-extensible sidebar slots
  • Session info, token counter, model picker in sidebar
  • Modified files / LSP status / MCP status widgets

Priority 5: Web UI Polish

  • Floating pill composer (ChatGPT pattern)
  • 260px collapsible sidebar with session list
  • Spring-physics button animations
  • Dyslexic font support

Priority 6: Killer Features

  • Ambient mascot/avatar (Petdex-style)
  • Cost/token display in prompt footer
  • Retry countdown timers
  • Copy-on-select
  • Braille streaming spinner

Deferred (not this sprint)

  • Multi-agent collaboration modes (Plan/Pair/Execute)
  • /ide IPC bridge to external editors
  • Worktree isolation for parallel sessions
  • Shader-like post-render effects (tachyonfx)
Implementation Notes
  • Use existing Harbor.DesignSystem tokens for all new components
  • Animations via Harbor.Desktop.Animations tokens (Fast=150ms, Normal=300ms)
  • ConsoleEx animations should be frame-tick driven, no layout thrash
  • Avalonia animations via XAML Transitions + GPU compositing
  • Blazor animations via CSS transitions + JavaScript interop
  • One commit = 1-2 files, atomic changes
  • Tests after each commit
