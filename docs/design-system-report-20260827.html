Interaction Patterns

Keyboard Shortcuts
Ctrl+C abort turn
Ctrl+C twice → quit
Ctrl+W delete word
Ctrl+Y yank
Ctrl+Z undo
Ctrl+Shift+Z redo
Alt+D delete fwd
M-s/i/c bold/italic/code
M-h/l heading/list
PageUp scroll
Animation Guidelines
Micro 100–150ms — hover, focus, button press
Standard 200–300ms — panel open/close, expand
Easing ease-out для entrance, ease-in для exit
TUI frame-tick driven, no layout thrash
Desktop Avalonia animations, GPU-composited
Accessibility
Contrast ≥ 4.5:1 for normal text, ≥ 3:1 for large
Focus visible indicator on every interactive element
Keyboard all actions reachable without mouse
Screen reader ARIA labels for desktop, semantic TUI cells
Platform Adaptations
Terminal 16/256/true-color fallback, cell-based layout
Avalonia XAML tokens, GPU render, native controls
Blazor CSS custom properties, responsive grid
Shared Ui.Framework state + reducers across all
