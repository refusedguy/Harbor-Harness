Sprint 1: UI-V2 (immediate)

Goal: Make Harbor visually competitive with modern AI coding tools.

Priority 1: Animations & Transitions

  • Panel fade-in/slide-in: 150ms fast, 300ms normal, ease-out
  • Tool cards slide-in + fade
  • Approval gate pulse/warn glow
  • Status bar smooth transitions between states
  • Timeline smooth scroll + opacity transitions
  • Spring physics для panel resizing

Priority 2: Command Palette & Navigation

  • Command Palette (ctrl+p) с fuzzy search + suggested commands
  • Quick-switch slots для recent sessions
  • Leader-key system для power users
  • Vim mode toggle для composer

Priority 3: Theme System Expansion

  • Multiple built-in themes: Harbor Dark, Light, Warm, Cool
  • Custom JSON theme support с live-reload
  • OSC 11 auto-theme detection
  • Per-component theme overrides

Priority 4: Sidebar & Context Panels

  • Optional right sidebar (42px default, auto-show на wide terminals)
  • Plugin-extensible sidebar slots
  • Session info, token counter, model picker в sidebar
  • Modified files / LSP status / MCP status widgets

Priority 5: Web UI Polish

  • Floating pill composer (ChatGPT pattern)
  • 260px collapsible sidebar с session list
  • Spring-physics button animations
  • Dyslexic font support

Priority 6: Killer Features

  • Ambient mascot/avatar (Petdex-style)
  • Cost/token display в prompt footer
  • Retry countdown timers
  • Copy-on-select
  • Braille streaming spinner
Sprint 2: Multi-Agent Orchestration

Goal: Enable concurrent agent execution with proper isolation and aggregation.

Phase 1: Fleet Manager

  • Git worktree isolation для каждого агента
  • Agent lifecycle management (spawn, monitor, terminate)
  • Dashboard/Kanban view для active agents

Phase 2: Subagent Delegation

  • ISubAgentRunner implementation с own session
  • Context isolation + shared task lists
  • Result aggregation через diffs

Phase 3: Shared Context

  • ISharedContextStore для cross-agent state
  • Living spec synchronization
  • Conflict resolution через human review

Phase 4: Coordinator Pipeline

  • Coordinator/Executor/Verifier roles
  • Plan/Pair/Execute collaboration modes
  • Multi-agent UI: split-pane terminals, agent tabs

Phase 5: Standards & Compatibility

  • ACP compatibility
  • MCP server support в IDE
  • Worktree isolation для parallel sessions
Sprint 3: Performance & Scale

Goal: 60fps rendering, zero GC pressure, fast startup, 10k+ message handling.

Rendering Performance

  • SIMD row hashing для diff engine
  • Zero-alloc markdown→ANSI pipeline
  • BitmapCache для static chat rows
  • Pooled Cell arrays

Memory Management

  • LOH compaction after history loads
  • String interning для repeated UI tokens
  • GC pressure profiling в CI

Startup Time

  • NativeAOT для CLI backend
  • ReadyToRun для Avalonia
  • Lazy module loading

Large Datasets

  • Data-virtualized chat source (10k+ messages)
  • Incremental loading для transcripts
  • VirtualizingStackPanel с BufferFactor tuning

Benchmarking

  • Extend BenchmarkDotNet suite: DiffEngine, render blit paths
  • Allocation-budget CI gates
  • 60fps timeline assertions
