### #1553 — аргумент-гарды CLI говорят одним словарём

**Перепись, измеренная на `dev@73c0b485` (`src/` + `apps/`).**

| форма | мест |
|---|--:|
| `ArgumentNullException.ThrowIfNull` + `ThrowIfNullOrWhiteSpace` + `ThrowIfNullOrEmpty` | 259 |
| `throw new ArgumentNullException(...)`, написанное руками | 166 (из них 161 без своего текста — переводятся 1:1) |
| `Ensure.NotNull` / `NotBlank` / `NotEmpty` — хелпер из #1605 | 286, в 24 проектах |
| `is null` | 781 (из них 166 бросают) |
| `IsNullOrWhiteSpace` | 341 (из них 22 бросают) |

Итого 425 гардов-бросаний и три словаря на одну работу.

**Блок.** `apps/Harbor.App.Cli/` — командная поверхность CLI — нёс 41
BCL-гард в 20 файлах и один рукописный `?? throw`. Все 42 стали
`Ensure.NotNull(...)`: 28 файлов, +29 / −28 строк, одна форма вызова.

`apps/Harbor.App.Cli.csproj` объявляет ссылку на `Harbor.Extensions` явно, а
не наследует её через `Harbor.Application`: CLI связывает `Ensure` сам, а
несущая ссылка записывается, а не достаётся по счастливой случайности. CLI —
композиционный корень, поэтому матрица слоёв
(`tests/Harbor.Architecture.Tests/FullLayerMatrixTests.cs`, она покрывает
только `src/`) не двигается.

**Что даёт хелпер, чего не даёт BCL-хелпер.** `Ensure.NotNull` возвращает
значение, поэтому рукописная форма схлопывается:

```csharp
_store = store ?? throw new ArgumentNullException(nameof(store));
_store = Ensure.NotNull(store);
```

и текст исключения получает имя параметра — хелпер берёт его из
`CallerArgumentExpression`: «Value cannot be null. (Parameter 'x')» вместо
«Value cannot be null.». Измерено: ни один тест в дереве не проверяет старый
текст (0 совпадений «Value cannot be null» под `tests/`).

**Что дальше по переписи.** Хелпер теперь на 328 местах, BCL-хелперы — на
218. Крупнейшие оставшиеся блоки и их цена по слоям:

| блок | BCL-мест | рукописных | цена |
|---|--:|--:|---|
| `src/Harbor.Tui.CellForge.Engine/` | 52 | 5 | строка матрицы пуста (`[]`, лист над BCL) — ребро было бы утверждением об архитектуре |
| `src/Harbor.Terminal.Abstractions/` | 36 | 0 | одна строка матрицы получает `Harbor.Extensions` (Domain, то же направление, что уже есть у строки) |
| `src/Harbor.Plugins.Hosting/` | 15 | 21 | одна строка матрицы |
| `src/Harbor.Registries/` | 11 | 1 | одна строка матрицы |
| `src/Harbor.Abstractions.Contracts/`, `src/Harbor.Abstractions/` | 19 | 1 | ничего — оба уже ссылаются на лист |

Словарь всё ещё не один: 85 из 328 вызовов `Ensure` (26%) написаны полностью
квалифицированно, потому что в тех файлах нет
`using Harbor.Abstractions.Extensions;`. Этот блок использует короткую форму
во всех 28 файлах; остальное — работа следующей волны.

**Что намеренно не сделано.** Рукописные `throw new ArgumentNullException` с
своим текстом оставлены как есть: `Ensure.NotNull` проксирует BCL-хелпер и
текст потерял бы. Переводимы 1:1 только сообщения без своего текста, и в
этом блоке такой ровно один.
