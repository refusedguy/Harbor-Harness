### #2083 — полоса `ci` может умереть тихо, и теперь это ловит гейт, а не GitHub

**Workflow-файл с дублирующимся ключом в маппинге — это файл, который GitHub отказывается разбирать, и отказ молчаливый.** Прогон создаётся, в нём **ноль джобов**, он закрывается как `failure` с текстом «This run likely failed because of a workflow file issue». Полоса не красная — её нет. Каждый PR, который её ждёт, ждёт вечно, и никто не видит, почему.

**Это произошло здесь, 2026-10-21.**

| прогон | дерево | джобов | итог |
|---|---|---:|---|
| 39613662649 | dev@165813bf | 16 | success — последний прогон с джобами |
| 39627731779 | dev@e7479b9a | 0 | failure |
| 39627783779 | dev@259d0a5d | 0 | failure |

Причина — `e7479b9a` (#2115): трём шагам отчёта шарда добавили arm64-близнеца и записали его как второй `if:`/`shell:`/`run:` **внутри** маппинга первого шага, на том же отступе. YAML не допускает дубля ключа в маппинге, поэтому файл, который читал GitHub, содержал три маппинга с `if:` дважды.

**Что сделано.** Три шага разбиты на шесть: близнец — отдельный шаг со своим именем. Плюс **гейт `check-workflows`**, который читает все workflow-файлы и падает, когда один маппинг объявляет ключ дважды. YAML он не читает: в стандартной библиотеке Go нет YAML-парсера, а дубль ключа — это вопрос про структуру файла, а не про значения. Сканер идёт по блочной структуре по отступам: элемент списка открывает маппинг на колонке текста после дефиса, `name:` — ключ маппинга, который владеет его отступом, тело блочного скаляра (`run: |`) — содержимое, а не структура.

**Гейт живёт в документационной полосе, и это не выбор вкуса.** Гейт, который polices `ci.yml`, не может жить в `ci.yml`: сломанный `ci.yml` уносит с собой и свой гейт — именно так вся полоса погасла без красной проверки. `docs.yml` стартует на каждом PR, с .NET-сборкой и без.

**Гейт нашёл дефект на дереве, на котором написан, и назвал три сломанных шага до строки:**

```
.github/workflows/ci.yml:2426  duplicate key "if" (first declared at line 2420)
.github/workflows/ci.yml:2452  duplicate key "if" (first declared at line 2446)
.github/workflows/ci.yml:2471  duplicate key "if" (first declared at line 2465)
```

На починенном дереве он зелёный, на остальных шестнадцати workflow-файлах молчит. Self-test — двенадцать фикстур: настоящая форма (шаг с двумя `if:`), ещё две из того же семейства и шесть форм, которые легальны и должны молчать (тот же ключ в двух соседних маппингах, тот же ключ в двух вложенных маппингах одного шага, блочный скаляр, тело которого выглядит как маппинг, последовательность простых скаляров, два одинаковых элемента списка, чистый файл). Гейт, который ругался бы на каждый шаг дважды, выключили бы через неделю.

Пол — `--min-files 17`, число workflow-файлов в дереве: скан, который перестал совпадать, уменьшит число, и джоб станет красным вместо «дерево чистое».
