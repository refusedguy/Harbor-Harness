### #1727 — снято правило тира C `ProjectKeyedScanRule`: перепись каталогов без csproj с покрытым инвариантом

**Что сделано.** Удалён файл `tests/Harbor.Architecture.Tests/ProjectKeyedScanRule.cs` (360 строк, 4 теста) и его запись в `tests/Harbor.Architecture.Tests/rule-tiers.json`. Правило сравнивало множество каталогов `src/` без `.csproj` с записанными именами `MeasuredCsprojLessFolders`. Тир C: 8 → 7, цена 2: 21 → 20, guards 158 → 157. Причина удаления записана в массиве `removals` JSON и в разделе «Post-audit removal (#1727)» документа `docs/ARCH_RULES.md`.

**Почему можно снять.** Заголовок файла прямо называл его «a MEASUREMENT, not a fix». Из четырёх проверок только одна сравнивала живое дерево с записанным списком имён, остальные три проверяли сам измеритель: множество проектов не пусто, каталог с `.csproj` не классифицируется как бесклассовый, ни один каталог не сирота. Все четыре строки graded форму дерева. Новый каталог без `.csproj` сдвигал базу, а починка требовала правки самого гварда. Это и есть определение правила, привязанного к форме, из аудита #1725/#1727.

**Инвариант не потерян.** Единственная проверка с видом дефекта, `EveryCsprojLessFolder_IsCompiledIntoSomeProject`, полностью покрыта `SharedSourceLinkRules` (GUARD для #456). Её R1 `Every_Csproj_Less_Source_Folder_Is_Declared` падает на новый незадекларированный каталог без `.csproj`, R3 `Every_Declared_Shared_File_Is_Linked_By_At_Least_One_Project` падает на файл, который ни один проект не линкует, а `Every_Declared_Folder_Has_At_Least_One_Consumer` падает на каталог, который никто не использует. Таблицу деклараций держит `FullLayerMatrixTests.SharedSourceFolders`. Теряется только измерение «эти каталоги не являются ключами», которое по заголовку файла не ловило дефект. `ScanVisibilityRule` остаётся: его предметом является необъявленная граница фильтра общего сканера, живой контракт API, а не перепись. Прежний вердикт «keep both» в таблице дубликатов отменён на этом основании. `CsprojLessFolder` и `ProjectKeyedScanProbe` не имели потребителей вне файла. Единственные внешние ссылки, комментарий в `ScanVisibilityRule.cs` и две строки в `docs/ARCH_RULES.md`, обновлены на выживший гард. Преемник не нужен, потому что правило не ловило дефект.

**Не проверено локально.** По правилам смены dotnet, тесты и гейты запускаются только в CI. Локально проверены только содержимое JSON, арифметика счётчиков и ссылки в документации.
