### #1791, #2156 — парсер исходников архитектурного набора переписан на современные API

**Разбор дерева правил перестал быть главным тормозом шарда `arch`: тот же вердикт, на порядок меньше работы.**

**Что.** В `tests/Harbor.Architecture.Tests.Shared/` появился `SourceParse.cs` — подложка разбора, через которую читает весь набор правил: стриппер комментариев, лексер литералов и счётчик идентификаторов. У каждой функции есть «близнец» с прежней реализацией, и `SourceParseParityTests` утверждает, что новый и старый дают **байт в байт одинаковый вывод на каждом файле градуемого корпуса** (2 665 файлов `src/` + `apps/` + `tests/`). Это и есть требование: правило не должно начать ловить другое.

**Что именно поменялось в коде.**

* **Стриппер комментариев.** Было: две регулярки и `MatchEvaluator`, который читал `match.Value` — свойство, материализующее подстроку — **внутри** цикла, обнуляющего комментарий. Было `n × n` символов аллокаций на комментарий длины `n`. Стало: один проход по `ReadOnlySpan<char>` с буфером из `ArrayPool<char>`, без строк на каждый символ.
* **Лексер литералов.** Было: `StringBuilder`, в который пишут по одному символу. Стало: тот же лексер, пишущий в буфер, который он уже держит, и `SearchValues<char>` + `IndexOfAny` для перехода к следующему символу, который вообще может что-то начать.
* **Счётчик идентификаторов.** Было: `Regex.Matches` по всему файлу — `Match` **и** `string` на каждый идентификатор каждого файла дерева. Стало: `Regex.EnumerateMatches` (структура `ValueMatch`, без `Match`) плюс `Dictionary.GetAlternateLookup<ReadOnlySpan<char>>()` — строка материализуется только для токена, которого ещё не было в словаре. Границы токенов — те же, у регулярки.
* **`DeadPublicMemberRule`:** типы файла разбираются **только** в семи деревьях контрактов (224 файла из 2 665), а список членов обходится **один раз** на файл, а не по одному разу на каждый тип (был квадратичный «перебор внутри перебора»).
* **`DeadPublicInterfaceRule`:** тот же счётчик идентификаторов, тот же лексер литералов.

**Измерено** (в CI, `GC.GetAllocatedBytesForCurrentThread()` по одному потоку; числа — в отчёте агента).

**Что осталось красным.** Ничего в этом наборе; правка не меняет ни одного вердикта правила — это и проверяет тест паритета.
