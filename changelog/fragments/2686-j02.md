### #2686 J02: a forge client seam with a GitHub adapter

**What changed.** `harbor pr list` and `harbor pr view` read pull requests through `IForgeClient`. The first adapter is `GitHubForgeClient`, which calls `gh pr list` and `gh pr view` and prints normalized records with `number`, `title`, `state` and `url`. The JSON projection is a pure class. The adapter reuses the shared `GhProcessRunner`, so it adds no new process code to the product tree.

**Acceptance.** Tests feed JSON directly to the projection and check the printed fields, malformed input, non-object entries, the output cap and the single-record path. The verbs validate their arguments on the command line and write errors to stderr with a non-zero exit. Local dotnet, tests and gates were not run under the night-shift rules. CI is the check.

**Slice limits.** This is the read-only GitHub adapter. It does not add GitLab or Forgejo adapters, does not watch pull requests and does not store a link between a pull request and a session.
