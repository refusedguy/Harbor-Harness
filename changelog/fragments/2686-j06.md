### #2686 J06: `harbor handoff` packages a PR for another session

**What changed.** A new `harbor handoff --session <id> --pr <number>` verb prints a JSON handoff packet: the session id, the pull request's number, title, state and URL, the current worktree path, and a ready-to-paste prompt for the receiving session. The pull request is read through the existing forge seam, so the verb adds no new child-process code. The `handoff` verb is registered in the CLI catalog, CAF dispatch and completion word list.

**Acceptance.** Packet shaping is pure: tests feed a forge pull request directly and check every field, the prompt contents and determinism. A missing flag, an invalid number, a failed forge read or an unreadable pull request gives a message on stderr and a non-zero exit.

**Slice limits.** This prints a packet; it does not send it, persist a session-to-PR link or switch worktrees. Local dotnet, tests and gates were not run under the night-shift rules. CI is the check.
