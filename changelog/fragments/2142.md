### #2083 — полоса `ci` молча исчезла: workflow с дублирующимся ключом не запускает ни одного джоба

**`ci.yml` перестал парситься — и полоса не стала красной, она исчезла.** GitHub читает файл, натыкается на дублирующийся ключ в маппинге и создаёт прогон с нулём джобов. Прогон закрывается как `failure` с текстом «This run likely failed because of a workflow file issue», и ни одного теста не запускается.

| прогон | дерево | джобов | итог |
|---|---|---:|---|
| 39613662649 | dev@165813bf | 16 | success — последний прогон с джобами |
| 39627731779 | dev@e7479b9a | 0 | failure |
| 39627783779 | dev@259d0a5d | 0 | failure |

**Причина — `e7479b9a` (#2115, «четырнадцать гейтов переезжают из python в один бинарь»).** Трём шагам отчёта шарда добавили arm64-близнеца (шарды живут на `ubuntu-24.04-arm`, а закоммичен был только x64-бинарь), и близнеца записали как второй `if:`/`shell:`/`run:` **внутри** маппинга первого шага, на том же отступе:

```yaml
      - name: Report test measurements (issue #618)
        if: always() && runner.arch == 'X64'
        shell: bash
        run: |
          tools/bin/harbor-gates-linux-x64 test-measurements ...
        if: always() && runner.arch == 'ARM64'   # ← дубль ключа `if`
        shell: bash
        run: |
```

YAML не допускает дублирующегося ключа в маппинге, поэтому файл, который читает GitHub, содержал три маппинга с `if:` дважды, `shell:` дважды и `run:` дважды. Та же форма была в `ci.yml:2446` (census) и `ci.yml:2465` (skipped tests).

**Правка — 6 вставок, 3 удаления, один файл.** Близнец стал отдельным шагом со своим именем: замысел сохранён (по бинарю на архитектуру), а читатель лога видит, какой бинарь отработал.

**Чего правка не делает.** Ничто в репозитории не может поймать workflow-файл, который GitHub отказывается разбирать: гейт, который должен бы это поймать, живёт внутри этого же файла, и вместе с ним исчезает. Проверка «в workflow-маппинге нет дублирующегося ключа» должна жить в ДРУГОМ workflow (документационная полоса или nightly) — это отдельное изменение, здесь его нет. Проверка перед пушем сделана локально: все 17 файлов `.github/workflows/*.yml` разбираются YAML с проверкой на дублирующиеся ключи, 0 отказов (до правки `ci.yml` падал на строке 2426).
