tests/Harbor.E2E.Framework/MockLlmServer.cs | Serialize(args) | #1822: SetToolCallResponse takes an OPEN `object` payload whose runtime type is chosen by the CALLER. Eighteen call sites across the PTY scenario suite and the CLI E2E suite pass anonymous types (`new { path = probe }` and friends), and a source-generated context registers types BY NAME — an anonymous type has no name, and the runtime's nearest-ancestor fallback would resolve it to `object` and silently drop every member. The way out is for the callers to pass a NAMED payload (the shared kit's ToolPathArgs and its siblings), which makes the method generic over the payload type; that change belongs to the slice that owns the PTY scenario files.
