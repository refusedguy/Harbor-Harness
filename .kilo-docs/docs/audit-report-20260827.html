Critical Finding: ConsoleEx Isolation
ConsoleEx is NOT used by any other platform. Ansi/Plain/Avalonia/Blazor/SpectreTui/TerminalGui/Termina/RazorConsole all have their own renderers.
ConsoleEx does NOT inherit BaseTuiRenderer or implement ITuiRenderer. It has own frame loop, widgets, diff engine, ScreenBuffer, PanelFx.
Only shared dependency: Harbor.Ui.Framework.State (UiStore/reducers) + Harbor.Terminal.Abstractions types.
This is architectural accident — ConsoleEx was built later as standalone high-performance stack without integrating into existing hierarchy.
Renderer Unification Proposal

Current State

  • Two parallel abstraction layers: legacy ITuiRenderer + canonical BaseTuiRenderer
  • ConsoleEx: 11.5k LOC standalone, cell-diff, zero-alloc, sixel/kitty
  • Ansi/Plain: ~80% duplicated code, both inherit BaseTuiRenderer
  • Blazor: demo shell, hardcoded transcript, no real streaming
  • No shared business logic layer — each platform reimplements widgets

Proposed Architecture

Shared Business Logic Layer (Harbor.Ui.Framework.Rendering)
- ChatScreenLayout (block ordering, measurement)
- DiffBlock (unified-diff parsing, gutters)
- ApprovalGateView (state machine, keyboard hit-test)
- StatusViewModel (mode transitions, segments)
- StreamingMarkdownRenderer (token-by-token parse)
ConsoleEx (rename to Harbor.Tui.ConsoleEx → Harbor.Tui.CellDiff)
- Keep all optimizations: PanelFx, Graphics, DiffEngine, ScreenBuffer
- Wrap as ITuiRenderer via adapter
- Becomes "high-performance backend" for shared business logic
Other Platforms (Ansi/Plain/Avalonia/Blazor)
- Use shared business logic + platform-specific renderers
- Ansi/Plain: merge into single AnsiPlainRenderer with escape-code strategy
- Avalonia/Blazor: adopt shared widgets, render via native controls
Proposed Sprint: "Renderer Unification & ConsoleEx Integration"

Goals

  • Extract shared business logic from ConsoleEx into Harbor.Ui.Framework.Rendering
  • Rename Harbor.Tui.ConsoleEx → Harbor.Tui.CellDiff (keep as optimized backend)
  • Wire CellDiff into BaseTuiRenderer/ITuiRenderer via adapter
  • Merge Ansi/Plain duplication into single renderer
  • Add visual regression tests for all platforms
  • Wire Blazor to real agent streaming

Quick Wins
