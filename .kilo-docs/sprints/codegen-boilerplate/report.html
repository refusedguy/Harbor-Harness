Design notes

  • Attribute delivery: Attributes/HarborCodeGenAttributes.cs is excluded from the analyzer assembly (netstandard2.0 per RS1041) and shared-source linked into consumers; generators match by fully-qualified metadata name — no assembly coupling.
  • Escape semantics preserved: SGR param order (1;2;3;4;9;7), 24-bit fg/bg encoding, CUP clamping — byte-identical output pinned by pre-existing golden frames; none regenerated.
  • FrameIndex semantics preserved: truncating division (not floor) replicated exactly — (-5/8)==0 → index 0; negative-tick wrap only via negative modulo; Sleeping advances 1 frame per 8 ticks.
  • RendererAdapterGenerator: literal-false boundary backends emit no-op bodies instead of runtime if — avoids CS0162 under warnings-as-errors.
  • Sprint prompt vs reality: names in the prompt (MoodBrain, IRoundRobinRenderer, IP-ProtocolCodec, AnsiPlain/EscapeCodes.cs) map to real code: MascotDirector/AmbientMascot, the four BaseTuiRenderer backends, EscapeCodes/EscapeCodeStrategy.cs. Acceptance criteria were applied to the real targets.

Concurrency incident & mitigations

This worktree was simultaneously processed by two agents on this same sprint (dispatched 08:57 and 09:28) plus a third on ci-cd-maturity. Incidents and the rules adopted:

  • Vacuum commit: a pathspec-less git commit swept the other session's staged test files into 5c8c56f (content correct, message mislabeled; history left untouched — no amend/reset under concurrency).
  • Rule adopted: stage explicitly, commit with explicit pathspecs only; re-check git status immediately before every commit.
  • Work partitioning: per-file claim tracking via git log/git status — this session claimed Task 3 + docs (untouched by the other session), Task 1 was the other session's, Task 2 left to its owner.
  • MSBuild node crashes (MSB4166): concurrent hook builds (2 agents × per-commit gates) exhausted build nodes; mitigated with -m:1 builds, dotnet build-server shutdown between collisions, and pre-commit retry after settling.
