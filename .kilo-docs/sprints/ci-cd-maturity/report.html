1 · Почему perf-gate падал с «Zero tests ran», exit 5

Корневая причина. Репозиторий через global.json включает режим MTP-only (test.runner = Microsoft.Testing.Platform). Workflow использовал VSTest-эпохи аргумент --logger trx, который MTP-хост не понимает: сессия обрывается с «Zero tests ran» и exit code 5 до запуска каких-либо тестов. Это не [NotInParallel] и не фильтры — сами тесты исправны.
  • Фикс (52687b3): убран --logger; per-test вывод (включая строки метрик [perf]) получается через --output Detailed — MTP-совместимый путь.
  • Отбор тестов в TUnit/MTP — --treenode-filter, НЕ --filter (задокументировано в комментариях workflow и AGENTS.md).
  • Защита от «тихих нулей»: критичные шарды получают --minimum-expected-tests 1 — регрессия «0 тестов» падает с exit 8, а не зелёится.
  • Acceptance «green на push в dev» — выполнен: run 33462711590 (PR) и последующие на dev — success.

4 · Release, benchmark, security

  • release.yml (61c8541): тег v* → матрица rid linux-x64 / linux-arm64 / win-x64, self-contained single-file publish с ubuntu-latest (runtime-pack'и из NuGet — кросс-OS publish без self-hosted), zip-архивы, GitHub Release с changelog-нотами. Проверка полного цикла возможна только первым реальным тегом — до этого job считаем «готов, но не прогнан» (в rubicon-отчёте — жёлтый допуск).
  • benchmark.yml (df8bf7d): PR-gate на путях src/** — BDN Short-job подмножество горячих путей из docs/BENCHMARKS.md (PermissionRuleset, реестры), markdown-таблицы в job summary, полные артефакты BDN для диффа. Не блокирует green при шумах — отчётный гейт.
  • codeql.yml (4b39e54, фикс языка bd5f1a8): csharp + security-extended, weekly cron + push/PR в mainline. GitHub secret scanning включается на уровне org/repo настроек — workflows его не дублируют; push protection рекомендуется включить в Settings → Code security.
  • dependabot.yml (df8bf7d): nuget (CPM-корень /, т.к. версии в Directory.Packages.props) + github-actions, еженедельно, группа minor+patch, лимит 10 PR.
  • demo-gifs (бонус, ae854a5): vhs 0.11 не знает Set FPS — все 4 tape-файла переведены на Set Framerate; после фикса globs (beee5a8) workflow зелёный.

6 · Известные ограничения / осознанные компромиссы

  • Золотые пиксель-тесты и жёсткий memory-бюджет — report-only/skip на shared runner'ах, с явными strict-переменными (HARBOR_GOLDENS_STRICT, HARBOR_MEM_BUDGET_STRICT) для закреплённых машин. Это конвенция репо (perf-gate стримился так же).
  • E2E-шард запускается с guard=false: TUI/E2E сьюты легитимно self-skip'ятся в PTY-ограниченных песочницах — это задокументированное поведение, а не тихий провал.
  • release.yml ожидает первый тег v* для полного цикла; рецепт publish воспроизводим локально (комментарий в шапке workflow).
  • История содержит два смежных коммита DI-фикса (0d4f1f6, de9d2d1) — параллельный агент и эта сессия дошли до одного корня одновременно; итоговое состояние файла консистентно (добавлен USERPROFILE для Windows).
